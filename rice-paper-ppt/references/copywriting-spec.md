# PPT 文案语言与表达规范（原文存档）

> 这份文档是文案层的**验收标准**，与 `typography-spec.md`（视觉层）配套使用。
> 视觉规范管字号、间距、版式；本规范管标题、正文的措辞、句式、术语与标点。
>
> 写每一页文案前读第 01–06 节；成稿后逐页执行第 08 节审查。
> 文末「最终要求」与 `typography-spec.md` 的「大而不乱，满而不挤」同级，冲突时按各自领域分别适用。
>
> 原文照录，未做删改。文中出现的禁用句式仅作反例，不得在幻灯片中出现。

## 01｜总体语言风格

采用专业、严谨、自然、简洁的书面表达，符合正式教学课件、技术汇报、项目答辩及商业演示的语言习惯。

- 以事实、观点、数据、技术机制和实际成果为表达主体。
- 直接陈述核心信息，避免迂回铺垫。
- 消除明显的 AI 生成痕迹、机械化句式及模板化表达。
- 保持专业性，不刻意追求语言的哲理性、文学性和传播性。
- 不使用缺少实际信息的口号式、营销式表达。
- 使用符合中文书面语言习惯的语序和标点符号。

## 02｜禁止使用的语言表达

除非存在必要的逻辑关系，否则禁止使用以下句式及其变体。

**机械化对比句式：**

- 不是……而是……
- 不仅是……更是……
- 不只是……还要……
- 与其……不如……
- 从……走向……
- 让……真正……
- 不再是……而成为……

**口语化、引导式表达：**

- 一句话说清这份材料要交付什么
- 一句话讲明白
- 我们先来看一下
- 接下来我们看看
- 说白了就是
- 简单来说
- 换句话说
- 你需要知道的是
- 这意味着什么
- 为什么这么说

**空泛总结与营销式表达：**

- 真正实现价值跃迁
- 打造全新的生态闭环
- 开启全新篇章
- 赋能千行百业
- 重塑行业格局
- 释放无限潜能
- 让技术真正落地
- 打通最后一公里
- 实现从 0 到 1 的突破

**冗余连接词：**

减少使用"首先、其次、再次、最后、与此同时、值得注意的是、进一步来说、从某种意义上讲、由此可见"等连接性表达。

优先通过标题层级、内容分组、编号、图表及排版结构体现逻辑关系，而非依赖大量连接词组织内容。

## 03｜标题命名与标点符号规范

标题应准确概括页面内容，优先采用名词短语、专业术语或具有明确事实依据的结论性短句。

- 一级标题建议控制在 4～16 个汉字。
- 二级标题建议控制在 4～12 个汉字。
- 结论型页面标题可适当延长，但应保持简洁。
- 标题包含主题与子主题时，使用中文全角冒号。
- 标题存在并列关系时，使用顿号、逗号或其他符合语义的标点。
- 标题存在解释、限定或补充关系时，可使用破折号或括号。
- 名词短语型标题末尾通常不添加句号。
- 不得为了视觉简洁而删除标题内部必要的标点符号。
- 禁止将多个语义单元直接堆叠为没有标点的长标题。
- 避免口号式标题、口语化标题及无必要的设问式标题。

示例：

| 不规范标题 | 规范标题 |
|---|---|
| 一句话说清这份材料要交付什么 | 交付目标与成果 |
| 核心技术 RAG 检索增强生成 | 核心技术：RAG 检索增强生成 |
| 项目背景 行业现状与发展趋势 | 项目背景：行业现状与发展趋势 |
| 从技术研发到真正实现应用落地 | 技术研发与应用实施 |
| 不只是知识展示而是智能学习 | 智能学习功能体系 |
| 为什么我们需要这样一个平台 | 平台建设需求 |
| 数据知识模型应用四层协同 | 数据、知识、模型与应用四层架构 |

## 04｜正文语言规范

- 每句话仅承载一个主要信息点。
- 优先采用"主体＋动作＋对象"或"技术方法＋实现功能"的表达结构。
- 正文使用完整、明确的陈述句，避免主语缺失和语义模糊。
- 功能描述直接说明功能对象、实现方式及实际作用。
- 技术描述明确技术名称、实现机制和应用场景。
- 成果描述优先使用可验证的数据、实际产出和实施结果。
- 同级条目的句式结构、信息粒度和语言风格应保持一致。
- 完整陈述句使用句号，短语型条目可统一省略末尾标点。
- 删除与页面主题无关的过渡句、引导语和解释性废话。

## 05｜专业术语使用规范

- 优先使用所属行业、技术领域及学科体系中的标准术语。
- 同一概念在整套 PPT 中保持命名一致，不随意替换近义词。
- 专业缩写首次出现时，根据受众需要补充完整名称。
- 不滥用"赋能、闭环、生态、抓手、跃迁、重构"等抽象词汇。
- 不凭空创造技术概念，不夸大技术能力和项目成果。
- 不编造数据、案例、性能指标和结论。

## 06｜信息密度与内容组织

- 每页围绕一个核心主题组织内容。
- 每个内容模块只表达一个相对独立的观点。
- 优先采用短标题、关键要点、数据指标、流程图和结构图表达信息。
- 删除重复解释、重复结论及同义反复。
- 页面标题已经表达的内容，正文不再进行机械复述。
- 不强制每页添加总结句、金句或价值升华。
- 不为填充页面空间而增加无实际意义的文字。
- 不为追求简短而牺牲专业信息的完整性。

## 07｜语言优化示例

| 原始表达 | 优化表达 |
|---|---|
| 平台不是简单的知识展示工具，而是一个智能化的学习空间。 | 平台提供知识检索、智能问答与个性化学习服务。 |
| 通过 AI 技术，让传统文化真正活起来。 | 利用生成式 AI 实现传统文化内容的数字化与交互式呈现。 |
| 一句话说清这套系统是如何运行的。 | 系统运行机制 |
| 不仅能够完成数据检索，还能够进一步实现智能分析。 | 支持数据检索与智能分析。 |
| 从真实工程项目走向可持续的人才培养。 | 基于真实工程项目构建人才培养体系。 |
| 首先完成数据采集，其次进行数据清洗，最后实现知识入库。 | 数据采集 → 数据清洗 → 知识入库 |
| 让知识不再孤立，而是形成相互连接的知识网络。 | 基于知识图谱建立实体之间的语义关联。 |

## 08｜生成后的语言审查

完成 PPT 文案生成后，逐页执行语言审查：

1. 检查是否存在机械化对比句式和 AI 模板化表达。
2. 检查标题是否准确、简洁，内部标点是否完整。
3. 检查是否存在多余的连接词和口语化引导语。
4. 检查是否存在抽象口号、空泛结论及夸大描述。
5. 检查专业术语、数据口径及模块命名是否统一。
6. 检查正文是否存在重复信息和无效文字。
7. 检查同级标题和条目的语法结构是否一致。
8. 检查页面内容是否符合正式书面表达规范。

发现上述问题时，直接修改后再输出最终 PPT 文案，不展示语言审查过程。

**最终要求：以准确传递信息为首要目标，以专业术语建立表达体系，以页面结构体现逻辑关系，以规范标点保证语义完整。输出成熟、自然、严谨的 PPT 文案。**
