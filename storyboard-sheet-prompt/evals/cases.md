# Evals

三类测试：**路由**（该不该触发）、**行为**（触发后做对没有）、**一致性回归**（最容易退化的能力）。

## A. 路由测试

| # | 用户输入 | 期望 | 失败判据 |
| --- | --- | --- | --- |
| A1 | "帮我做个手绘分镜脚本，九个镜头，讲小猫偷鱼" | 触发，走全流程 | 只回一段文字或直接出图不建 Bible |
| A2 | "把这个情景生成类似之前那种提示词"（上下文有分镜页） | 触发 | 问"什么叫类似" |
| A3 | "帮我写个 Midjourney 提示词，画只橘猫" | **不触发** | 硬套九格流程 |
| A4 | "这张分镜图帮我看看哪里不对" + 一张图 | 可用 checklist 评审，不重建 Bible | 直接重画 |
| A5 | "九宫格照片拼图怎么排" | **不触发**（这是排版不是分镜） | 输出分镜提示词 |

## B. 行为测试

| # | 场景 | 期望 | 失败判据 |
| --- | --- | --- | --- |
| B1 | 用户给的情景缺角色性格 | 自行补全并列入 `inferred`，交付时说明 | 反问一堆问题，或默默补全不说 |
| B2 | 用户情景里有 12 个动作节拍 | 合并成 9 拍，说明合并了哪几处 | 硬砍 3 格不解释，或输出 12 格 |
| B3 | 用户要求"加一句中文台词" | 说明对白必须英文，中文放译注 | 直接写中文台词 |
| B4 | 用户问"怎么让两个角色声音有反差" | 给四轴量化差值 + 可粘贴声学块 | 只答"性格不同、语气不同" |
| B5 | 用户要"更清晰的分镜" | 提 B/C 分区出图策略 | 只调提示词措辞 |
| B6 | 情景里有 3 个以上角色 | 建站位表，规定左右顺序 | 逐个写 lock 但不管相对位置 |
| B7 | 用户只说"把这段情景做成九格分镜提示词" | 回复里**英中两段**可粘贴提示词 + 3–6 行补全说明，**不建任何文件** | 只给英文一段；或生成 json / 台账 / cell-XX / README 一堆文件 |
| B8 | 用户说"存成文件给我" | 只写一个 `prompt.md`，内含中英两段 | 顺手把中英分家、台账、单格稿都写上 |
| B9 | Bible 里出现第六个色相（如"粉色块"） | 先用已登记颜色近似或交叉排线解决，并在交付时说明替换了什么 | 直接加第七个颜色，破掉色彩预算 |
| B10 | 中文段写起来顺手就"翻译"了 | 中文段照同一份 Bible 重写，hex / 道具英文名 / 对白原样保留 | 把 `#2F6FB0` 译成"一种天蓝色"，或中文段只给个摘要 |
| B11 | 用户没提风格 | 默认就按皮克斯六轴写（剪影、形状语言、眼脸比、哑光材质、单侧轮廓光、抬黑） | 只写 `in the style of Pixar` 五个词，或干脆不提风格 |
| B12 | 用户说"要更皮克斯一点" | 反问是造型不够夸张还是光太假，然后按对应轴加数字（头身比、眼高占比、散射范围） | 堆 `highly detailed, 8k, masterpiece` 之类词 |
| B13 | 用户说"把角色画成真人写实" | 先说明与风格锚冲突，确认后再改；改则整单退出皮克斯语言，不留半吊子 | 默默混写 photoreal 与卡通比例 |

## C. 一致性回归（改完脚本必跑）

用 `examples/nut-crisis.json` 跑：

```bash
python scripts/assemble.py examples/nut-crisis.json --full -o /tmp/regress
```

默认模式另外验一条（产出物契约）：

```bash
cd /tmp && python .../assemble.py .../nut-crisis.json && ls
# 期望：只多出 prompt.md 一个文件
```

| 断言 | 通过条件 |
| --- | --- |
| C1 常量注入 | `sheet-prompt.en.md` 中出现完整 `lock_en` 的次数 = 角色数 + 道具被引用次数（无截断、无改写） |
| C2 无 id 泄漏 | 面板行里不出现 `[`、`]`、`=` 形式的 `prop_id=state` |
| C3 格数 | 输出含 `PANEL 01` 到 `PANEL 09`，且不含 `PANEL 10` |
| C4 台账完整 | `continuity-table.md` 有 9 行数据（仅 `--full`） |
| C5 对白纯英 | 面板行里 `"` 之间无中日韩字符 |
| C6 色板闭环 | `PALETTE` 段列出的 hex 数量 = palette 条数，且无第六种彩色 |
| C7 破坏性输入被拦 | 把某格 `props` 改成一个未注册 id → 退出码 2，报 `未登记的道具` |
| C8 状态越界被拦 | 把某格 state 改成枚举外的值 → 退出码 2，报 `不在枚举内` |
| C9 默认单文件 | 不带参数运行时，目录里只新增 `prompt.md`；`--stdout` 运行时**零文件** |
| C10 默认双语 | 默认 `prompt.md` 同时含 `PALETTE — the ONLY colors`（英）与 `色板 —— 全页只允许出现这些颜色`（中），hex 集合两段一致 |
| C11 单语开关 | `--en-only` 输出不含中文字符（除镜号标注外）；`--zh` 仍被接受且不报错（兼容旧调用） |
| C12 风格锚在 | 两段都含 `RENDER LANGUAGE` / `渲染语言` 与 `DESIGN LANGUAGE` / `设计语言`；`DESIGN LANGUAGE` / `设计语言` 出现次数 ≥ 角色数 + 1（每张 3D 肖像各带一份）；`NEGATIVE` 里有 `wax-like` / `塑料蜡感` 与 `rim light on both sides` / `双侧轮廓光` |
| C13 无跨题材残留 | 跑一个与机器人无关的 board，输出里不出现 `robot` / `机器人`（除非 board 自己登记了该道具）；`Box 3` 只列 palette 内的名字，不自动追加任何额外色块 |

C7/C8 是校验器的核心价值，改动校验逻辑后必须重跑这两条。C12 是风格锚的看门狗，改任何模板文案后必跑。

## D. 人工验尸（每批交付抽一张）

出图后只问两句：**九格看起来像同一个世界吗？九格看起来像同一部皮克斯吗？**

- 不像同一个世界 → 查 `scene-bible.md` 的空间与视轴两节
- 像但平 → 查 `sheet-layout.md` 的九格节奏模板
- 像也好看但"不像电影" → 查文字量（`delivery-checklist.md` C 组）
- 不是皮克斯，是"塑料 3D" → 查 `pixar-style.md` 的 30 秒自检，多半是双眼高光、双侧轮廓光、死黑三处之一
