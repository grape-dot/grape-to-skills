# 版式规格：分镜脚本页

## 画布

- **16:9**，横向。等效 3840×2160 起（低于 2K 九格必糊）。
- 背景：干净白纸，带极轻的纸纤维纹理与四边轻微暗角，**不要**做旧发黄——那是"旧档案"，不是"前期会议桌上的新稿"。
- 全页保持**单一平面俯视**：这是一张纸的照片/扫描件，不是立体场景。提示词里写 `flat overhead scan of one sheet of paper, no perspective on the paper itself`。

## 分区比例

```
┌───────────────────────────────────────────────────────────┐
│ 镜头1.1.1至1.1.9                     SC 1.1 · NUT CRISIS   │  ← 页眉 8%
├──────────────────────────────────┬────────────────────────┤
│                                  │  CHARACTER DESIGN      │
│   ┌────┐ ┌────┐ ┌────┐           │  & CASTING             │
│   │ 01 │ │ 02 │ │ 03 │           │  ┌──────────────────┐  │
│   └────┘ └────┘ └────┘           │  │ A: 名字          │  │
│   ┌────┐ ┌────┐ ┌────┐           │  │ [素描]   [3D]    │  │
│   │ 04 │ │ 05 │ │ 06 │           │  │ 图注             │  │
│   └────┘ └────┘ └────┘           │  ├──────────────────┤  │
│   ┌────┐ ┌────┐ ┌────┐           │  │ B: 名字          │  │
│   │ 07 │ │ 08 │ │ 09 │           │  │ [素描]   [3D]    │  │
│   └────┘ └────┘ └────┘           │  │ 图注             │  │
│                                  │  ├──────────────────┤  │
│                                  │  │ VILLAIN / PROPS  │  │
│                                  │  └──────────────────┘  │
├──────────────────────────────────┴────────────────────────┤
│ [ 笔记/流程意图 ]  [ 镜头/故事笔记 ]  [ 色彩调色板 ]        │  ← 页脚 18%
└───────────────────────────────────────────────────────────┘
```

- 页眉 6–8%
- 左区 **63–66% 宽**，右区 30–33%，中间留一道 3% 的手绘竖分隔线（可略斜）
- 页脚 16–20%，三个框宽度比约 `1 : 1.15 : 0.85`

九格占左区：**3 列 × 3 行的严格网格**，格宽 : 格高 = 16:9。格间距 ≈ 格宽的 4%。九格加起来的面积要留出每格下方 3–6mm 的手写标注带——**标注写在格子外面**，不要压在画面里，否则出图必糊。

## 每格的构成

```
┌─────────────────────────┐
│  [细红框 1.5–2px]        │  ← 画面只在框内
│                         │
│                         │
└─────────────────────────┘
 01 · NEAR          ↗ blue note
 手写动作说明（1 行，≤8 词）
```

- 镜号在框外**左下**，数字大、手写体
- 镜别标签（NEAR / MED-WIDE / WIDE）在镜号右侧，小一号
- 蓝箭头从画面内某处引出，**画在框外**，箭头尖端指向框内目标，尾端接 2–5 词手写注释
- 动作说明一行，短句，别写完整语法

## 红框的规定

**细**，1.5–2px，正红偏暖（#C0392B 附近），手绘感——四条边不严格平行，角部轻微出头。这是"用红笔圈构图"的痕迹，不是 PPT 描边。

反面：加粗到 6px、加阴影、加圆角、四色描边。一旦精致化，整页的"前期手稿"气质就没了。

## 九格节奏模板

镜别单调是这类页面最常见的失败。**默认节奏**（可直接用）：

| 格 | 镜别 | 作用 |
| --- | --- | --- |
| 01 | NEAR | 立"任务感"——把道具拍成武器 |
| 02 | MEDIUM | 交代双人关系与"计划" |
| 03 | NEAR | 动作启动，最有张力的一格 |
| 04 | NEAR | 意外介入（反派登场） |
| 05 | MED-WIDE | 拉开空间，展示体量反差 |
| 06 | MEDIUM | 卡在瓶颈（喜剧高点前置） |
| 07 | NEAR | 崩塌/失败，画面最乱 |
| 08 | NEAR (beauty shot) | 反转——温情空降 |
| 09 | WIDE | 收尾，全貌 + 余韵 |

硬规则：

- 同镜别**不得连续 3 格**。上面模板第 03/04 是两连 NEAR，第 05 必须拉开。
- 第 5 或第 6 格必须有一次**尺度跳跃**（WIDE 或 MED-WIDE），否则"厨房巨大 / 仓鼠渺小"这个喜剧来源不成立。
- 第 8 格建议 `beauty shot`：柔光、浅景深、构图正中，和第 7 格的混乱形成断崖。这个断崖就是全片的情绪拐点。
- 第 9 格必须是 WIDE，把前八格的空间关系一次性收拢。

## 手写文字规范

**这是最容易崩的一环。** 出图模型能画 2–4 个词的漂亮手写，5 个词开始飘，超过 8 个词必成乱码。

允许出现文字的五个位置：

1. 左上镜号（中文，如「镜头1.1.1至1.1.9」）—— 字数固定，风险低
2. 每格镜号（`01`）与镜别（`NEAR`）
3. 每格动作说明（≤ 8 词）
4. 蓝箭头注释（2–5 词）
5. 图注（2 行，每行 ≤ 12 字符）

不允许：整段英文、段落式镜头说明、页眉大段 title block。

**写中文还是英文**：页面正文的标签、注释、图注用**英文**（模型对英文手写更稳，也更符合"好莱坞前期文档"质感）；只有左上角的大镜号用**中文**，因为那是你的工作习惯标记，且字数固定。

## 混合媒介配方

整页要有**三种笔**的痕迹：

| 媒介 | 用途 | 提示词关键词 |
| --- | --- | --- |
| 石墨铅笔 | 所有分镜画面、右侧素描、色块排线 | `loose graphite pencil sketch, visible construction lines, smudged hatching` |
| 红墨 | 分镜框、镜号下划线 | `thin red ink frame, slightly wobbly hand-drawn stroke` |
| 蓝墨 | 箭头、注释 | `blue ballpoint arrow, quick confident stroke, tapered tail` |
| 3D 渲染 | 右侧两张角色肖像 + 道具小图 | `Pixar-style 3D render, subsurface scattering, soft rim light` |

**关键对比**：左侧是粗糙的手绘，右侧是精细的 3D。这个媒介冲突正是"提案页"的魅力——不要把 3D 也画成手绘，那两头都不到岸。

## 常见崩坏点

| 崩坏 | 症状 | 预防写法 |
| --- | --- | --- |
| 格数错 | 出现第 10 格、空格、2×5 布局 | `exactly nine panels arranged in 3 rows and 3 columns` 写在提示词最前 |
| 文字糊 | 格子下方出现乱码段落 | 标注用 2–5 词，绝不写句子 |
| 框变粗 | 红框变成装饰边框 | `thin 1.5px red ink, hand-drawn, slightly uneven` |
| 右栏被挤掉 | 角色卡只剩半张脸 | 右栏宽度写进提示词（`right panel occupying the right third`） |
| 九格同一镜别 | 全是大头照或全是全景 | 每格显式写 `NEAR` / `MED-WIDE` / `WIDE`，并对照节奏模板 |
| 3D 塑料感 | 角色像玩具 | 加 `subsurface scattering`、`individual fur strands`、`wet catchlights` |
| 页脚三框消失 | 只剩两框或被裁 | `three handwritten boxes across the bottom` + 框宽比 |
| 颜色跑偏 | 出现第六种彩色 | 色板 hex 全写出，并加 `no color outside this palette` |

## 单格放大版（cell sheet）

当用户要"关键帧高清版"时，不要复用整页提示词，另出单格：

- 画布仍是 16:9，但**只画这一格**，红框保留（保留红框 = 保持"这是分镜"的身份）
- 镜号与动作说明放在框外下缘
- 角色锁、道具锁、色板、光位全部原样复制
- 细节可以加满（布纹、灰尘、水渍），因为不用塞九格了

`assemble.py` 会给每格自动生成这种单格稿。
