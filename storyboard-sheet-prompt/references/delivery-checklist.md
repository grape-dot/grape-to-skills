# 交付前自检清单

按顺序过，前五组有任一项不过，别交付。

## 0. 交付物（先查这组，最容易翻车）

- [ ] 默认情况下，回复里是**两段**可粘贴提示词（英文 + 中文）+ 3–6 行补全说明
- [ ] 中文段是完整版，不是节选 / 摘要 / 只译开头几行
- [ ] 中文段照着同一份 Bible 写：hex、道具英文名、镜别、对白与英文段逐项对得上
- [ ] 没有为了"看起来专业"而多写文件（json / 台账 / cell / README / 索引）
- [ ] 用户要文件时，只写了一个 `prompt.md`（里面仍是中英两段）
- [ ] 说清了"我替你补了什么"（3–6 行，不是一篇说明文）

## S. 皮克斯风格锚（硬约束，每组都要过）

- [ ] 两段里都有 `RENDER LANGUAGE` / `渲染语言` 段，不是只写了 `in the style of Pixar`
- [ ] 两段里都有 `DESIGN LANGUAGE` / `设计语言` 行，且跟在角色锁后面
- [ ] 眼高写成了约占脸高 1/3，头身比写成了具体数字（幼态 1:2–1:3）
- [ ] 每个角色只有一种主动力形状（圆 / 方 / 三角），没有混用
- [ ] 写了"一处刻意的不完美"
- [ ] 次表面散射限定在毛边 / 耳 / 鼻 / 颊，没有全身发亮
- [ ] 轮廓光只在一侧，且写明了方向
- [ ] 写了暗部抬黑、高光滚降（`lifted blacks` / `no clipped white`）
- [ ] 负面段里有：塑料蜡感、镜面高光、双侧轮廓光、处处黄金时刻、死黑、切白、死鱼眼
- [ ] 纸面仍然是石墨分镜页，没把整页做成 3D 渲染

## A. 一致性（最重要）

- [ ] 每一格出现的每个物件，都能在道具注册表里找到 id
- [ ] 同一物件，九格用的是同一串英文名（没有同义改写）
- [ ] 角色造型锁在九格里逐字相同，且 `anchors` 每格至少出现两件
- [ ] 造型锁里显式写了 `no clothing, no accessories`
- [ ] 颜色只来自色板，没有第六种彩色
- [ ] 每个色有排他用途（毛色不用于道具，反之亦然）
- [ ] 光位九格一致（除非剧情有昼夜跨越且已声明）
- [ ] 视轴九格未翻转（反打已显式标注）
- [ ] 道具状态链闭合，没有出现"消失后又出现"
- [ ] 状态转移合法（走的是 `states` 枚举里的值）

## B. 版式

- [ ] 正好 9 格，3 行 × 3 列，提示词首段已写死
- [ ] 每格 16:9，红框细（1.5–2px）、手绘、略抖
- [ ] 标注写在框**外**
- [ ] 右侧 1/3 有「CHARACTER DESIGN & CASTING」，两角色各有素描 + 3D + 图注
- [ ] 右栏底部有反派/道具小卡
- [ ] 底部整整三个手写框
- [ ] 左上角有中文手写镜号
- [ ] 全页是"一张纸的俯视扫描"，不是立体场景

## C. 文字量

- [ ] 每格动作说明 ≤ 8 词
- [ ] 蓝箭头注释 2–5 词
- [ ] 图注 2 行，每行 ≤ 12 字符
- [ ] 全页没有段落式文字
- [ ] 对白每格 ≤ 2 句、每句 ≤ 8 词，且写在框外

## D. 节奏

- [ ] 同镜别未连续 3 格
- [ ] 第 5 或 6 格有尺度跳跃（MED-WIDE / WIDE）
- [ ] 有至少一格是 WIDE，且在第 9 格
- [ ] 第 8 格是 beauty shot（柔光/浅景深/正中构图）
- [ ] 第 7 格到第 8 格有明确的情调断崖

## E. 语音（若交付含对白）

- [ ] 对白全英文，无中文混入
- [ ] 每句都能通过"互换测试"（换给另一个角色说会明显不对）
- [ ] 两个角色的音高中心差 ≥ 一个八度
- [ ] 语速差 ≥ 1.8 倍
- [ ] 混音距离不同（贴麦 / 离麦已指定）
- [ ] 有一个"全场唯一一次情感暴露"的点（通常是倒数第二格）

## F. 诚实性

- [ ] 所有自行补全的设定都列进 `inferred`，并在交付时说了一句
- [ ] 如果一张图信息密度过高，明确告知了 B/C 两种替代出图策略
- [ ] 没有把"我推断的"说成"你要求的"

## 一句话验尸

生成出来后，只看一眼就问自己：**九张图像不像发生在同一个房间里？**

不像 → 回去查 A 组。像但不吸引人 → 查 D 组。像也好看但"不够电影" → 查 C 组文字量。
